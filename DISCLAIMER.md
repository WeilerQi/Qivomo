## 1. What this product is

Qivomo is a **local input-mapping tool** for Android devices. It works by deploying a native daemon under the `shell` user through Shizuku, taking over the physical keyboard, mouse and gamepad input devices, and translating that input into touch events on the screen.

To be explicit, this product:

- does **not** modify, replace or inject into any game file or game process memory;
- does **not** read, tamper with or forge any traffic between a game and its servers;
- does **not** crack, bypass or interfere with any anti-cheat or anti-tamper mechanism;
- does **not** provide aim assist, wallhacks, speed hacks, macro farming or any other cheat-like feature.

It is only a translation layer that turns key presses into finger taps; its scope is the same as the system's built-in accessibility features and external input device support.
